# PC3000E-6 Troubleshooting Assistant — berbasis Troubleshooting Guide

Aplikasi web statis untuk dibuka melalui Chrome Android atau GitHub Pages. Tidak memakai AI dan tidak membuat prosedur baru.

## Isi paket
- Indeks teks seluruh 264 halaman PDF `03._Troubleshooting_Guide.pdf`.
- Pencarian lokal untuk trouble code/Message, gejala (termasuk SHY/SME/SAD), dan seluruh halaman manual.
- Filter kategori sistem berbasis kata kunci; kategori adalah bantuan pencarian, bukan diagnosis otomatis.
- Detail teks halaman serta tautan membuka halaman yang sama di PDF asli, sehingga diagram dan gambar asli dapat dilihat.
- Data kasus (unit, HM, tanggal), catatan pengukuran, laporan TXT, salin, dan berbagi WhatsApp.

## Pasang ke GitHub Pages dari HP Android
1. Ekstrak ZIP.
2. Unggah semua isi folder `pc3000_v9` ke root repositori GitHub.
3. Pastikan `guide_pages.json`, `guide_entries.json`, `Troubleshooting_Guide_PC3000E6.pdf`, `index.html`, `app.js`, `style.css` ikut terunggah.
4. Buka website GitHub Pages setelah deploy selesai.

## Batasan penting
- Teks indeks diambil dari PDF; beberapa gambar/diagram tidak dapat diubah menjadi teks. Gunakan tombol “Buka halaman ini di PDF asli” untuk melihat diagram.
- Pencarian tidak mengubah alur prosedur; setiap prosedur harus dibaca dari halaman aslinya dan diverifikasi terhadap serial number serta konfigurasi unit.
- Ini bukan pengganti Shop/Service Manual, diagram khusus unit, LOTOTO, atau teknisi kompeten.
